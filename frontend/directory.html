💉 Module 2 – SQL Injection: UNION-based Data Extraction

In a vulnerable search endpoint, user input is embedded directly in a LIKE clause. An attacker can inject a UNION SELECT statement to append data from any other table in the database (e.g. the users table with usernames and passwords).

UNION attack requirements: The injected SELECT must return the same number of columns as the original query (6 columns here).

Example payload:
' UNION SELECT username, password, role, email, 1, 1 FROM users --
⚠️ VULNERABLE MODE – Input is concatenated into the SQL LIKE clause without parameterisation.
✅ SECURE MODE – Input is bound via parameterised query. UNION injection is impossible.
