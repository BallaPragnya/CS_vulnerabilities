💉 Module 4 – Reflected XSS (Cross-Site Scripting)

In a vulnerable search page, the search term is reflected back into the HTML response without escaping. If the search term contains HTML or JavaScript, the browser executes it.

An attacker can craft a URL with an XSS payload in the query string and trick a victim into clicking it. When the victim opens the link, the script runs in their browser under the application's origin.

Example payloads:
<img src=x onerror="alert('XSS!')"> — classic image error XSS
<b style="color:red">Injected!</b> — HTML injection
<script>alert('XSS')</script> — inline script (some browsers block)
⚠️ VULNERABLE MODE – Search term reflected with innerHTML. JavaScript in the input will execute.
✅ SECURE MODE – Search term set with textContent (safe output encoding). All HTML is treated as plain text.
