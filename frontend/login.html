💉 Module 1 – SQL Injection: Authentication Bypass

In a vulnerable login form, user input is embedded directly into the SQL query string. An attacker can break out of the string with a single quote and append extra SQL logic that makes the WHERE clause always evaluate to TRUE — bypassing the password check entirely.

Demo table: Uses an isolated sqli_demo_users table with plain-text passwords. It is completely separate from the real login system.

⚠️ VULNERABLE MODE – Input is pasted directly into the SQL string (no parameterisation).
✅ SECURE MODE – Input is bound via a parameterised query (? placeholder).
