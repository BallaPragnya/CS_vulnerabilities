💉 Module 3 – OS Command Injection: In-Band

In a vulnerable diagnostics tool, user input is embedded directly in a shell command string. child_process.exec() passes the full string to the system shell, which interprets special characters like & | ; as command separators.

An attacker can append extra commands after the hostname and they will execute on the server.

Example payloads (Windows):
127.0.0.1 & whoami — runs whoami after ping
127.0.0.1 & hostname — reveals the server hostname
127.0.0.1 & echo hacked — echoes custom text
Linux: 127.0.0.1; whoami or 127.0.0.1; hostname

🔒 Safety note: This demo blocks genuinely destructive commands (rm, del, format, shutdown, etc.). Only harmless built-ins are allowed.

⚠️ VULNERABLE MODE – Uses exec(command_string). Shell metacharacters are interpreted.
✅ SECURE MODE – Uses execFile(program, [args]). No shell spawned. Input validated with allowlist regex.
